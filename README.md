# AICTE CaseSync Frontend Prototype

React + TypeScript + Vite + Tailwind prototype based on the supplied Lovable screenshots.

Run:
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. `npm install`
4. `npm run dev`

The AI is a clearly labelled local prototype simulation. Cases are persisted in browser localStorage. No paid API is required.
